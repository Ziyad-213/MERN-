Q 1.1

Explain basic programming concepts in Python.

Python is a high-level, interpreted, dynamically-typed programming language. Key concepts include:

  • Interpreter: Python executes code line by line at runtime.
  • Indentation: Python uses indentation (4 spaces) instead of braces to define code blocks.
  • Dynamic Typing: Variable types are determined at runtime \u2014 no need to declare them.
  • Comments: Single-line comments use #; multi-line use triple quotes """...""".
  • print(): Built-in function to display output.
  • input(): Reads user input as a string.
# Basic Python program
name = input("Enter your name: ")
print("Hello,", name)

# Arithmetic
a, b = 10, 3
